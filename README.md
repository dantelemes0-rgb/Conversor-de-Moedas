# DevClub Convert Money

Conversor de moedas desenvolvido com HTML, CSS e JavaScript.

## Moedas disponíveis

- Real brasileiro
- Dólar americano
- Euro
- Bitcoin
- Libra esterlina

## Como executar

Abra o arquivo `index.html` no navegador.

As taxas de conversão estão definidas no arquivo `scripts.js` e são valores demonstrativos.
